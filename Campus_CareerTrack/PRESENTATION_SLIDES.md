## Slide 2 — Problem Statement
Students often track internships, job openings, deadlines, and application updates across multiple websites, spreadsheets, and messages. This can make it difficult to compare opportunities and remember the next action.

**Problem:** A single, organized view of placement opportunities and application progress is useful for students.

Visual: scattered job listings → one organized dashboard.

## Slide 3 — Proposed Solution
Campus CareerTrack is a student-focused web portal that brings sample opportunities and application tracking together.

- Explore internships and entry-level roles
- Search and filter by type, location, domain, and skills
- Save interesting opportunities
- Submit a validated demo application
- Track application status
- Maintain a student profile

## Slide 4 — Objectives
1. Build a clean, easy-to-use interface.
2. Demonstrate HTML forms and semantic page structure.
3. Use CSS for a responsive dashboard layout.
4. Use JavaScript for DOM manipulation, events, search, filtering, and validation.
5. Persist demo information using browser localStorage.
6. Design a foundation that can be extended with PHP and MySQL.

## Slide 7 — System Workflow
1. Student opens the dashboard.
2. Student searches or filters sample opportunities.
3. Student saves a role or opens the application form.
4. JavaScript validates required fields and formats.
5. A valid application is stored in localStorage.
6. The dashboard and application list update immediately.

Visual flow: **Browse → Select → Validate → Save → Track**.

## Slide 8 — Validation and Testing
- Required name, email, motivation, and consent
- Email format validation
- Optional portfolio URL must use HTTP or HTTPS
- Motivation text length is checked
- Duplicate applications to the same role are blocked
- Search and filters update results
- Data persists after a page refresh

Visual: screenshot of a validation error and successful submission toast.

## Slide 9 — Current Limitations
- Opportunities are fictional sample data
- Data is stored only in one browser
- No real account login or server-side database
- No live company vacancy feed or recruiter notifications

These limits are intentional for a client-side Review 01 prototype.
